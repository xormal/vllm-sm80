# Первый запуск кандидата на GPU0–1

2026-10-28, разрешение владельца на остановку production и GPU-проверки. Код испытаний и запуска: `965a816dd`, runtime-пакет памяти: `aef8fa694`.

## Текущее состояние

Кандидат работает: `kandidat-validation.service`, API PID 2719858, `http://127.0.0.1:8086`, модель `Qwen3.8-27B-ABLITERATED-candidate`. После проб `/health` = 200. Внешний порт 8085 закрыт, ожидающие агенты на стенд не поступают. Production остановлен; прежний unit, launcher, конфиги, venv source path и Git-дерево проверены — не изменены. При перезагрузке остаётся прежний автозапуск. GPU2–3 не использовались.

Параметры сохранены: max_model_len=262144, max_num_seqs=16, batch=8192, TP2, MTP K4, KV=11295047936 байт/ранг, int8_per_token_head, Clef. FALLBACK_ROWS=0: новый кусочный fallback в этой серии не испытывался. Общий mixed Clef graph ещё не реализован.

## Сборка и ресурсы

Все 12 расширений из prewarm-списка, включая CG и Clef, построены в отдельном каталоге кандидата. Основной vLLM C-extension — ранее скопированный baseline binary; полной пересборки vLLM не было. CUDA C++ исходники этой итерацией не менялись. Первый prewarm занял около 25 минут.

Сборка: 6 ГиБ MemoryMax, 5 ГиБ MemoryHigh, swap=0, CPU400%, MAX_JOBS=2. Измеренный cgroup MemoryPeak=5368963072 байт (~5,00 ГиБ), high=114, max/oom/oom_kill=0. Сервер: MemoryHigh20G/Max21G, swap0, CPU1600%, Inductor compiler threads1; MemoryPeak=21477437440 байт (~20,00 ГиБ), max/oom/oom_kill=0. High срабатывал: числам времени нельзя приписывать отсутствие влияния host reclaim.

Первый shell-процесс не перешёл к API после успешной сборки (`PYEOF: command not found`): скрипт был обновлён во время исполнения Bash. Проверка синтаксиса прошла; повторный запуск прочитал актуальный файл, использовал готовые расширения и поднял API. Не редактировать выполняющийся shell launcher на месте. Системный Python управляющей обёртки теперь запускается с -I, чтобы не импортировать runtime sitecustomize без torch.

| Completion, 32 токена | HTTP200, нужное число токенов | 1,97 с |

| Prefill 32768 / 131072 / 212992 +16 токенов | все HTTP200, без OOM | 6,69 / 30,77 / 56,32 с |

16 HTTP-запросов не означают, что все 16 одновременно исполнялись на GPU: очередь и preemption контролируются прежним scheduler. Времена включают prefill/декод/HTTP, первые использования графов и холодных кэшей; это не замер установившегося throughput и не A/B со старым сервером. Длинные входы — повторяемый синтетический текст для проверки памяти; они не оценивают сохранение фактов/качество на длинном контексте.

Первый нетемплированный completion (`The capital of France is`, ignore_eos) дал `Paris` и повтор нулей. Это сохранено в basic.json, не принято за quality-pass. Chat-smoke корректен, но не снимает необходимость отдельной проверки деградации.

Из sampled NVML с шагом 500 мс максимум занятой памяти: GPU0=32302 МиБ, GPU1=32298 МиБ из 32768. Это наблюдавшийся максимум, не allocator peak; быстрые пики могли быть пропущены. Остаток около 466–470 МиБ **не доказывает достаточный запас** для mixed C8+R4 и не достигает предварительного ориентира резерва 512 МиБ. Монитор после серии остановлен; сервер оставлен работать.

В журнале старта есть два ERROR о недоступном штатном `_vllm_fa2_C` (по одному на ранг): те же сообщения были у production в 18:55. Vision encoder выбрал TORCH_SDPA, текстовый target — FA2_SM70. Это не новый отказ кандидата; пользовательские multimodal-запросы в этой серии не проверялись. После фактического запуска API traceback и CUDA OOM не зарегистрированы.

## Что ещё не принято

- A/B с исходным runtime, logits/Clef probabilities, длинные генерации и entropy-sensitive quality.
- Кусочный fallback 1024 против 0 с проверкой смены арифметики GEMM/TP.
- Mixed C8+R4, большой Clef, картинки, заполненные caches и длительный soak.
- Бюджет MTP graph pools и крупные временные матрицы sparse selector: новые production OOM 156/272 МиБ описаны в PLAN.md.
- Общий граф, асинхронная Clef head и p99 межтокенных задержек.

Успешные smoke-пробы не означают устранения всех OOM и не подтверждают сохранение качества/скорости.
